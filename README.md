## Initialize

```Bash
npm install

git clone git@github.com:CJey/hexo-theme-next.git themes/next
```

## Startup

```Bash
npm run server
```

OR

```Bash
npm run build # then serve static files in directory "public" by yourself
```

## Deploy

```Bash
npm run deploy
```
